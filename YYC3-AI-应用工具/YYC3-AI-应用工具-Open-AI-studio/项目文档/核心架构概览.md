# 🍒 Cherry Studio 项目架构深度解析

我已经完成了对 Cherry Studio 项目核心代码结构的全面分析。以下是详细的架构总结：

---

## 📐 整体架构设计

### 1. **技术栈概览**

```
┌─────────────────────────────────────────────────────────────┐
│                    Cherry Studio Architecture                │
├─────────────────────────────────────────────────────────────┤
│  前端框架: React + TypeScript + Tailwind CSS                │
│  桌面框架: Electron (Main + Renderer + Preload)              │
│  状态管理: Redux + Redux Persist                             │
│  数据查询: React Query (@tanstack/react-query)               │
│  AI SDK: Vercel AI SDK (统一 Provider 接口)                 │
│  包管理: pnpm Workspace (Monorepo)                          │
│  构建工具: Vite (electron-vite)                             │
└─────────────────────────────────────────────────────────────┘
```

## 🎯 核心设计模式

### 1. **分层架构**

```
┌─────────────────────────────────────────┐
│         Presentation Layer              │  ← React Components
│    (UI Components, Pages, Hooks)        │
├─────────────────────────────────────────┤
│         Business Logic Layer            │  ← Redux Store + Thunks
│  (State Management, Actions, Selectors) │
├─────────────────────────────────────────┤
│         Service Layer                  │  ← Main Process Services
│   (MCPService, KnowledgeService, etc.)  │
├─────────────────────────────────────────┤
│         Data Access Layer              │  ← Database / File System
│    (SQLite, FileStorage, etc.)         │
└─────────────────────────────────────────┘
```

### 2. **插件系统 (AI Core)**

```typescript
// 插件钩子类型
type PluginHook = "first" | "sequential" | "parallel";

// 插件接口
interface Plugin {
  name: string;
  hooks: PluginHook[];
  execute: (context: PluginContext) => Promise<void>;
}

// 内置插件
-webSearchPlugin - // 网络搜索
  toolUsePlugin - // 工具调用
  loggingPlugin - // 日志记录
  googleToolsPlugin; // Google 工具
```

### 3. **Provider 模式**

```typescript
// 统一的 Provider 接口
interface AIProvider {
  name: string;
  createModel: (config: ModelConfig) => LanguageModel;
}

// Provider 注册表
class ProviderRegistry {
  register(provider: AIProvider): void;
  get(name: string): AIProvider;
  listAll(): AIProvider[];
}
```

### 4. **IPC 通信模式**

```typescript
// IPC 通道定义 (IpcChannel.ts)
export enum IpcChannel {
  // 消息相关
  ADD_MESSAGE = "add-message",
  STREAM_MESSAGE = "stream-message",

  // 服务相关
  MCP_SERVER_START = "mcp-server-start",
  KNOWLEDGE_BASE_CREATE = "knowledge-base-create",

  // 系统相关
  WINDOW_MINIMIZE = "window-minimize",
  // ... 更多通道
}
```

### 5. **状态管理模式 (Redux)**

```typescript
// 切片模式
interface StoreSlice {
  name: string;
  state: State;
  reducers: Reducers;
  extraReducers: ExtraReducers;
}

// 示例切片
-assistants.ts - // 助手管理
  llm.ts - // LLM 配置
  knowledge.ts - // 知识库
  settings.ts; // 应用设置
```

## 📊 数据流架构

```
用户操作
    ↓
React Component (渲染进程)
    ↓
Redux Action / Thunk
    ↓
IPC Channel (preload)
    ↓
Main Process Service
    ↓
External API / Local Resource
    ↓
Response via IPC
    ↓
Redux Store Update
    ↓
Component Re-render
```

## 💡 架构亮点

1. **Monorepo 结构** - 使用 pnpm workspace 管理多包
2. **模块化设计** - 清晰的职责分离和模块边界
3. **插件化架构** - AI Core 插件系统支持灵活扩展
4. **类型安全** - 完整的 TypeScript 类型系统
5. **状态管理** - Redux + React Query 双重状态管理
6. **跨平台支持** - Electron 支持 Windows/Mac/Linux
7. **MCP 协议** - 标准化的 Model Context Protocol 集成
8. **多窗口架构** - 支持多种窗口类型和交互场景
