## 一、目录职责

本目录是**项目验收与上线闭环的唯一入口**：从项目起始门禁，到 13 个阶段的逐级验收，再到部署上线与稳定运维，全部标准集中于此。

## 六、目录不变量

1. 文件名统一 `YYC3-{主题}-{类型}.md`，阶段文档标注所属阶段
2. 全部文档复用同一「核心理念」块（五高 / 五标 / 五化 / 五维）
3. 全部文档使用《标头标尾》§二 标头与 §4.3 标尾
4. 阶段编号统一为「第 N 阶段」，不再混用「第 N 类」
5. 引用上游标准一律指向 `../YYC3-团队通用-标规文档/`
6. 日期基准统一 2026-11-01
