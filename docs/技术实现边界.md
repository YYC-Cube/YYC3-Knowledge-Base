## 一、功能实现详解

### 1. 模态框 + 卡片渲染 + 步骤深度链接

**模态框实现**（`#previewModal`）:

- 固定定位全屏遮罩层，`z-index: 200`，`backdrop-filter: blur(4px)` 背景模糊
- 居中弹窗，`max-width: 520px`，`max-height: 80vh`，溢出滚动
- `fadeUp` CSS 动画入场
- 关闭方式：点击 ✕ 按钮 / 点击遮罩层背景

**核心函数 `openPreviewModal(id)`**:

```
1. 根据 id 从 GUIDES 中查找匹配指南
2. 取 catColor 作为步骤编号色
3. 遍历 guide.steps 渲染每项：
   - ms-num: 圆形编号（绿色=已完成，catColor=未完成）
   - ms-title / ms-meta: 标题 + 耗时
   - ms-check: 已完成标记
4. modal-step 绑定 onclick → closePreviewModal(); showGuide(id, stepN)
```

**卡片渲染更新**（`renderDashboard()` 中的 `guides.forEach`）:

```
每张卡片新增三个区域：

┌──────────────────────────────────────┐
│ 📋 2/5              [图标]  ✓       │ ← gc-step-progress 徽章 + gc-check
│    1. Open WebUI + Ollama 部署       │
│    ⭐ 简单  ⏱ 30 min               │
│    在 DGX Spark 上一键部署...        │
│    [Docker] [sudo 权限]             │
│ ─────────────────────────────────── │
│ ⚡ 操作步骤                          │ ← gc-steps 区域
│  ① 配置 Docker 权限                 │ ← gc-step-item (点击跳转具体步骤)
│  ② 启动 Ollama 容器     ✓          │ ← gc-step-item (已完成标记)
│  ③ 下载 DeepSeek-R1                │
│  查看全部 5 步 →                    │ ← gc-step-more (打开模态框)
└──────────────────────────────────────┘
```

### 2. 步骤级深度链接导航

**URL 格式**: `#guide-g01-step-3`

**解析函数 `parseGuideHash(hash)`**:

```javascript
// 输入: "guide-g01-step-3"
// 输出: { id: "g01", stepN: 3 }
// fallback: "guide-g01" → { id: "g01", stepN: null }
```

正则: `/^([^-]+)-step-(\d+)$/` — 匹配 `g01-step-3` 格式

**应用点（3 处）**:

| 位置 | 作用 |
|------|------|
| `showGuide(id, stepN)` | 生成 hash: `guide-${id}-step-${stepN}` |
| `hashchange` 监听 | 解析 hash → 调用 `showGuide(parsed.id, parsed.stepN)` |
| `init()` 初始化 | 页面加载时解析初始 hash → 自动定位 |

**`showGuide()` 增强逻辑**:

```javascript
function showGuide(id, stepN) {
  // ...
  // 步骤展开逻辑
  const shouldOpen = !collapsed || (stepN && s.n === stepN);
  stepsHtml += `<div class="step ... ${shouldOpen ? 'open' : ''}" data-step="${s.n}">`;

  // hash 更新
  window.location.hash = 'guide-' + id + (stepN ? '-step-' + stepN : '');

  // 自动滚动
  if (stepN) {
    setTimeout(() => {
      const el = document.querySelector(`.step[data-step="${stepN}"]`);
      if (el) el.scrollIntoView({ behavior: 'smooth', block: 'center' });
    }, 150);
  }
}
```

**触发入口（3 条路径）**:

```
卡片步骤预览条 (gc-step-item)      → onclick → showGuide(id, stepN)
模态框步骤列表 (modal-step)         → onclick → closeModal + showGuide(id, stepN)
浏览器历史导航 (前进/后退)          → hashchange → parseGuideHash → showGuide
```

### 3. 卡片步骤完成进度

**存储结构**:

```
localStorage:
  guide-done-g01 = "1"         ← 整篇指南完成
  step-done-g01-1 = "1"        ← 第1步完成
  step-done-g01-2 = "1"        ← 第2步完成
  step-done-g01-3 = "1"        ← 第3步完成
```

**渲染判断**:

```javascript
// 步骤完成数
const stepsDone = g.steps
  ? g.steps.filter(s => localStorage.getItem('step-done-' + g.id + '-' + s.n) === '1').length
  : 0;

// 总步骤数
const totalSteps = g.steps ? g.steps.length : 0;

// 进度徽章 CSS class
const stepProgCls = stepsDone > 0 ? 'has-progress' : '';
```

**视觉反馈**:

```
📋 0/5  → 默认灰色边框, text3 色
📋 3/5  → 绿色边框 (border-color: rgba(34,197,94,0.3)), accent-e 色
```

**进度联动**:

```
toggleDone(id)        → 更新 guide-done-{id}
toggleStepDone(id,n)  → 更新 step-done-{id}-{n}
  → renderDashboard() → 重新计算每一张卡的 stepsDone / totalSteps
  → updateSidebarProgress() → 重新计算全局百分比
```

## 三、设计边界与延伸方向

### 当前边界

| 维度 | 边界 | 说明 |
|------|------|------|
| **数据量** | 40 篇指南，200+ 步骤 | 全量在单个 JS 文件中加载 |
| **存储** | `localStorage` (5MB 限制) | 每篇约 0.1KB，40 篇约 4KB，远未触及上限 |
| **并发** | 单用户 | 无服务端，纯本地操作 |
| **离线** | 完全离线可用 | 首次加载后全部资源在本地 |
| **搜索** | 标题匹配 | 基于 `includes()` 的简单全文搜索 |
| **分类** | 单标签 | 每篇只能属于一个分类 |

### 可延伸方向

#### 1. 数据层增强

| 方向 | 实现方式 | 价值 |
|------|----------|------|
| **Markdown 源文件加载** | `fetch('guides/g01.md')` 动态加载 | 数据可独立维护，支持社区 PR |
| **搜索升级** | 引入 `fuse.js` 模糊搜索 | 支持错别字容错、步骤内容搜索 |
| **多标签分类** | `tags: ['docker','llm','gpu']` | 交叉筛选更灵活 |
| **外部存储同步** | IndexedDB + 可选 WebDAV/S3 同步 | 突破 localStorage 容量，跨设备 |

#### 2. 交互升级

| 方向 | 实现 | 价值 |
|------|------|------|
| **步骤拖拽排序** | HTML Drag & Drop API | 自定义学习路径 |
| **笔记/批注系统** | 每步可追加 Markdown 笔记 | 个人知识沉淀 |
| **执行计时器** | 每步点「开始」→ 计时 → 点「完成」 | 准确追踪实际耗时 |
| **操作截图画廊** | 步骤内可嵌入截图并点击放大 | 可视化验证 |
| **终端模拟嵌入** | xterm.js 嵌入，一键执行命令 | 从"复制-粘贴"到"一键执行" |

#### 3. 架构扩展

| 方向　　　　　 | 实现　　　　　　　　　　　　　　　　　　　　　　　　　　| 价值　　　　　　　　　　　　　　　　|
| ----------------| ---------------------------------------------------------| -------------------------------------|
| **PWA 化**　　 | Service Worker + manifest.json　　　　　　　　　　　　　| 可安装到桌面/手机桌面，完全离线使用 |
| **多语言**　　 | i18n 数据层，`const GUIDES_ZH` / `const GUIDES_EN`　　　| 英文用户友好　　　　　　　　　　　　|
| **多项目切换** | GUIDES 命名空间化，如 `GUIDES.DGX_SPARK` / `GUIDES.NIM` | 同一平台管理多个产品线文档　　　　　|
| **Git 同步**　 | 检测 GUIDES 版本号，提示更新　　　　　　　　　　　　　　| 内容随仓库迭代自动同步　　　　　　　|

#### 4. 后端化路径

```
单体 HTML + JS
  │
  ├── 轻量 → Node.js 静态 API + JSON 数据
  │      GET /api/guides         → 返回 GUIDES
  │      GET /api/guides/:id     → 返回单篇
  │      POST /api/progress      → 服务端持久化进度
  │
  └── 全栈 → Next.js + shadcn/ui
         ├── /  → 看板页面 (Server Component)
         ├── /guide/[id] → 详情页面 (SSR)
         ├── /api/guides → API Route
         └── 数据库 PostgreSQL → 用户进度/笔记
```
