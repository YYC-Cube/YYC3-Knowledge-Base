## 一、目录职责

本目录承载 **24 个分类的可视化架构页**。每页以统一设计规范（暗色优先 / 单文件 / 卡片多级布局 / 零依赖）呈现该分类的：

- 规模统计（项目数、文件数、体积、技术栈数）
- 技术构成 TOP 10（按项目覆盖数）
- 迁移来源分布（原字母桶 / 领域桶）
- 项目清单（原始路径、技术信号、工程清单、版本变体标记）
