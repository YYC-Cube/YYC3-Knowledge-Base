## 使用方式

1. **复制**本节 Markdown 到章末或 PR 描述 / WorkBuddy 任务回复。  
2. **实测**列填数字或短文；**状态**填 ✅ / ❌。  
3. **问题清单**至少覆盖：超标破折号、禁用词、无来源精确数。
