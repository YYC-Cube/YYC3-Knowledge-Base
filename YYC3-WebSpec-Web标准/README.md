- 项目目录统一为 `YYC3-WebSpec-Web标准-{项目原名}`（《YYC³ 团队通用-命名规范》§5：路径与目录使用 ASCII `YYC3`）
- 原名中的空格统一归一为 `-`（如 `Accumulo 3.0.0` → `Accumulo-3.0.0`）
- `-v2` / `-v3` 后缀表示**同名但内容不同**的版本变体，非重复项，禁止直接合并
