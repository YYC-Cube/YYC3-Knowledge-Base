## 安全公告

微软高度重视软件产品和服务的安全性，这包括 GitHub 组织下所有源代码仓库。

**请勿通过公开 GitHub Issue 报告安全漏洞。**

有关安全报告的信息、位置、联系方式和政策，请查阅微软仓库的最新指南：
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md)

### 安全报告指引

| 场景 | 操作 |
|------|------|
| 发现安全漏洞 | 访问 [Microsoft Security Response Center](https://msrc.microsoft.com/create-report) 提交报告 |
| 一般安全问题 | 通过上述官方渠道联系安全团队 |
| 公开讨论 | **禁止** — 安全漏洞严禁在公开渠道披露 |

## Security

Microsoft takes the security of our software products and services seriously, which
includes all source code repositories in our GitHub organizations.

**Please do not report security vulnerabilities through public GitHub issues.**

For security reporting information, locations, contact information, and policies,
please review the latest guidance for Microsoft repositories at
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).

### Security Reporting Guide

| Scenario | Action |
|----------|--------|
| Vulnerability found | Report via [Microsoft Security Response Center](https://msrc.microsoft.com/create-report) |
| General security concern | Contact the security team via official channels above |
| Public discussion | **Prohibited** — never disclose vulnerabilities publicly |
