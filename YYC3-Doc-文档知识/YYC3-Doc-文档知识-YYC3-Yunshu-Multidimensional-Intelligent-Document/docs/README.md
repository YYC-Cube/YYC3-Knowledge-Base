## 文档命名规范

```
YYC3-Docs/
├── {2位序号}-YYC3-云枢智能-{4字大类}/          ← 分类目录
│   ├── {4位序号}-YYC3-{4字大类简称}-{内容}.md    ← 功能文档
│   └── README.md                                ← 分类索引
└── README.md                                    ← 总索引
```

- **大类名称**：统一使用 4 个中文字（如：基础架构、核心编辑、版本管理）
- **文件序号**：前 2 位为分类编号，后 2 位为文件序号（如：0101、0203）
- **文档标头**：统一 YAML frontmatter（file、description、version、status、tags 等）

---

## 维护指南

- **新增文档**：依据内容归属插入对应分类目录，按末位序号递增
- **文档更新**：在 YAML 头中递增 `version` 并更新 `updated` 日期
- **文档废弃**：将 `status` 标记为 `deprecated`，保留文件用于追溯
- **归档处理**：历史版本移入 `_archive/` 目录，保留原始命名
