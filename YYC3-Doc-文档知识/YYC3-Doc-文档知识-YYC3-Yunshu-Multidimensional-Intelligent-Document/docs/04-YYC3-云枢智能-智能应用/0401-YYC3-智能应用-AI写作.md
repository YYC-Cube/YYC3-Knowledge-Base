## 106.1 "AI 帮我写" 功能模块
针对不同文档类型提供场景化 AI 写作支持：

```javascript
// 场景化AI写作
sdk.ai.writeWithScenario({
scenario: 'meeting-summary', // 会议纪要/邮件/报告/需求文档
context: {
meetingTopic: '产品迭代规划',
duration: '2小时',
keyPoints: ['Q3功能清单', '开发排期', '资源分配']
},
style: {
tone: 'formal', // 正式/简洁/详细
structure: 'standard' // 标准/列表/结构化
}
}).then(content => {
sdk.insertContent(content, { position: 'cursor' });
});
// 基于选中内容扩展
sdk.ai.expandSelection({
direction: 'examples', // 举例/细节/背景/结论
count: 3 // 生成3个示例
}).then(expanded => {
sdk.insertAfterSelection(expanded);
});

对应文档中 "AI 帮我写" 功能，通过场景化参数提升 AI 生成内容的贴合度。

```
