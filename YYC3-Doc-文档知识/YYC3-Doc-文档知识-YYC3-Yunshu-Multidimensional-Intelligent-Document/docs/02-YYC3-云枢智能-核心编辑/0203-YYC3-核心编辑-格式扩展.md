## 三十六、小应用集成功能
文档支持插入各类小应用组件，扩展编辑器功能边界。以倒计时组件为例，实现代码如下：

```javascript
// 插入倒计时小应用
sdk.insertApplet({
type: 'countdown', // 对应文档中的倒计时组件
container: '#editor-container',
config: {
targetTime: '2025-10-01T00:00:00',
format: 'DD天HH时MM分SS秒',
endText: '倒计时结束',
style: {
color: '#F53F3F',
fontSize: '16px',
fontWeight: 'bold'
}
},
width: '100%',
height: '60px'
});
// 小应用通信接口
sdk.applet.onMessage('countdown', 'time-update', (data) => {
console.log('剩余时间:', data.remaining);
if (data.remaining < 86400000) { // 少于24小时
sdk.applet.updateStyle(data.instanceId, { color: '#FF7D00' });
}
});

其他小应用集成方式类似，支持自定义参数与样式，如天气、时钟等工具类应用。

```

## 三十九、内容保护区高级控制
文档支持精细化内容保护，可限制特定区域的编辑权限：

```javascript

// 创建内容保护区
sdk.createContentProtection({
id: 'confidential-section',
range: {
start: 500,
end: 1200 // 保护范围
},
permissions: {
edit: ['admin', 'editor1'], // 可编辑用户
comment: ['team-members'], // 可评论用户组
view: ['all'] // 可查看范围
},
style: {
background: 'rgba(242, 243, 245, 0.3)',
borderLeft: '3px solid #1890FF',
tooltip: '此区域受保护，仅管理员可编辑'
},
watermark: {
text: '内部机密',
opacity: 0.1,
rotation: -30
}
});
// 权限检查与申请
sdk.checkPermission('confidential-section', 'edit').then(hasPermission => {
if (!hasPermission) {
// 显示权限申请按钮
showPermissionRequestButton('需要编辑权限？点击申请');
}
});
// 临时权限申请
sdk.requestTemporaryPermission('confidential-section', 'edit', {
reason: '需要更新数据',
duration: '1h' // 临时权限时长
}).then(approved => {
if (approved) {
console.log('临时编辑权限已授予');
}
});

```

```javascript

container: '#editor-container',

height: '1px',
width: '100%',
margin: '16px 0'
}
});
// 分隔线样式切换
sdk.updateDivider(dividerId, {
type: 'dashed',
color: '#1890FF',
width: '80%', // 可设置百分比或固定像素

align: 'center' // 对齐方式：left/center/right
});

分隔线对应文档中提及的「分隔线」功能，通过简单的样式配置即可实现多样化的视觉分隔效果。

```

## 四十二、格式刷与批量格式处理

## 42.1 格式刷功能
实现格式复制与应用，提高格式统一效率：

```javascript
// 启动格式刷
sdk.activateFormatPainter({
source: {
start: 100,
end: 120 // 复制此范围的格式
},
mode: 'single' // single/multiple（单次/多次应用）
});
// 应用格式

sdk.applyFormatPainter({
target: {
start: 200,
end: 250 // 应用格式的目标范围
}
});
// 退出格式刷模式
sdk.deactivateFormatPainter();

```

## 四十四、查找与替换功能

## 44.1 文本查找
支持全文查找与定位，高亮显示匹配结果：

```javascript
// 执行查找
sdk.findText({
query: '文档',
caseSensitive: false, // 是否区分大小写
wholeWord: false, // 是否全字匹配
highlight: true, // 是否高亮显示
style: {
backgroundColor: '#FFF7E6',
color: '#865E00'
}
}).then(result => {
console.log(`找到 ${result.count} 处匹配`);
// 定位到第一个匹配项
sdk.navigateToMatch(0);

});
// 导航到下一个/上一个匹配
sdk.findNextMatch();
sdk.findPreviousMatch();

```

## 44.2 文本替换
支持单条或批量替换文本内容：

```javascript
// 替换单个匹配
sdk.replaceMatch({
index: 0, // 替换第几个匹配项
replacement: '文档编辑器'
});
// 全部替换
sdk.replaceAllText({
query: '文档',
replacement: '文档编辑器',
caseSensitive: false
}).then(result => {
console.log(`已替换 ${result.count} 处匹配`);
});

```

## 45.1 多格式导出
支持导出为 PDF、Word、HTML 等多种格式：

```javascript
// 导出文档
sdk.exportDocument({
format: 'pdf', // pdf/docx/html/markdown
options: {
includeHeaderFooter: true,
pageSize: 'A4',
margin: { top: '20mm', right: '15mm', bottom: '20mm', left: '15mm' },

});
```
