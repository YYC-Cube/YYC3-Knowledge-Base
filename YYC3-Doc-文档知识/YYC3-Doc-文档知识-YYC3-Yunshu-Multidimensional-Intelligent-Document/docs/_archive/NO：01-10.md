#### 1.1.1 文档元数据结构

**json**

```
{
  "doc_id": "uuid-v4",
  "title": "产品需求文档",
  "schema": {
    "version": "2.0",
    "fields": [
      {
        "name": "product_line",
        "type": "text",
        "options": ["硬件", "软件", "服务"]
      },
      {
        "name": "status",
        "type": "status",
        "state": "draft",
        "transitions": ["submit", "approve", "publish"]
      }
    ]
  },
  "relations": [
    {
      "target_doc_id": "related_doc_123",
      "relation_type": "dependency",
      "direction": "bidirectional"
    }
  ]
}
```

**技术实现**：参考飞书多维表格的双向同步机制，通过 `<span>relations</span>`字段定义文档间关联，支持 `<span>dependency</span>`（依赖）、`<span>parent-child</span>`（父子）等关系类型，采用 GraphQL 接口实现跨文档查询。

#### 1.1.2 动态数据关联

* **API 设计**：

**graphql**

```
query GetRelatedDocuments($doc_id: ID!) {
  document(id: $doc_id) {
    relations(type: "dependency") {
      target {
        title
        schema {
          fields(name: "status") {
            state
          }
        }
      }
    }
  }
}
```

**参考**：Flowmix Docx 的 API 抽象方法，将文档关系查询封装为 GraphQL 端点，支持实时数据同步。


**参考**：飞书多维表格的权限分级机制，结合 OAuth 2.0 的 scopes 模型，实现细粒度权限控制。

```
sdk.on('conflict', (conflict) => {
  switch (conflict.type) {
    case 'edit':
      // 自动合并文本修改
      sdk.resolveConflict(conflict.id, {
        strategy: 'merge',

      });
```
