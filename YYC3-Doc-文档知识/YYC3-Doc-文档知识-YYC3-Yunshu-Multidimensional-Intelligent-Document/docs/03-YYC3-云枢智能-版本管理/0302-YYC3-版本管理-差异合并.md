## 九十六、文档比较与差异合并

## 96.1 多版本差异可视化
支持多版本文档的并排对比与差异标记：

```javascript
// 比较两个版本的文档
sdk.compareDocuments({
baseVersion: 'v1.0',
targetVersion: 'v1.1',
viewMode: 'side-by-side', // 并排/上下/融合视图
highlight: {
added: '#E6FFED',
removed: '#FFF2F0',
modified: '#FFF7E6'
},
ignore: ['formatting', 'whitespace'] // 忽略格式和空格变化
}).then(comparison => {
sdk.renderComparisonView(comparison, {
container: '#diff-container',
showLineNumbers: true,
syncScroll: true // 同步滚动两个版本
});
});

```

## 96.2 选择性合并差异

```javascript

// 手动选择差异进行合并
sdk.mergeDocumentDiffs({
baseVersion: 'v1.0',
targetVersion: 'v1.1',
decisions: [
{ id: 'diff-123', accept: true }, // 接受此差异
{ id: 'diff-456', accept: false }, // 拒绝此差异
{ id: 'diff-789', merge: (base, target) => customMerge(base, target) } // 自定义合并

]
}).then(mergedDoc => {
sdk.applyMergedDocument(mergedDoc, {
createNewVersion: true,
comment: '合并v1.0与v1.1版本差异'
});
});

文档比较功能对应文档中 “文档比较”，通过可视化与选择性合并支持多版本管理。

```

## 九十七、模板变量联动与计算

## 97.1 变量依赖与动态计算
支持模板变量间的关联计算与条件逻辑：

```javascript
// 注册带联动变量的模板
sdk.registerTemplate({
id: 'budget-plan',
name: '预算计划模板',
variables: [
{ name: 'revenue', type: 'number', label: '收入' },
{ name: 'cost', type: 'number', label: '成本' },
{
name: 'profit',
type: 'computed',
label: '利润',
formula: (vars) => vars.revenue - vars.cost
},
{
name: 'profitRate',
type: 'computed',
label: '利润率',
formula: (vars) => vars.revenue > 0 ? (vars.profit / vars.revenue * 100).toFixed
(2) + '%' : '0%'
}
],
content: `# 预算计划
- 收入：{{revenue}}元
- 成本：{{cost}}元
- 利润：{{profit}}元
- 利润率：{{profitRate}}

`
});
// 变量变化联动更新
sdk.on('template-variable-change', (data) => {
if (data.templateId === 'budget-plan' && data.variable === 'revenue') {
console.log('收入变化，自动更新利润');
}
});

```
