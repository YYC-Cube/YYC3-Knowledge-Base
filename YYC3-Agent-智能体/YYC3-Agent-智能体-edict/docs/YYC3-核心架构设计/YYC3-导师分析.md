```
灾难场景分级：
┌─────────────────────────────────────────────────────────────────────┐
│ Level 1: 单节点故障（概率：高）                                     │
│   影响：某位 AI Family 成员暂时离线                                 │
│   恢复：K8s 自动重启（< 30s）                                      │
│   降级：该角色任务排队等待或转移给备用实例                           │
│                                                                     │
│ Level 2: 单 AZ 故障（概率：中）                                      │
│   影响：整个可用区服务中断                                           │
│   恢复：流量切换到其他 AZ（DNS 切换 < 60s）                         │
│   降级：关闭非核心功能（文娱/资讯），保留核心（聊天/任务）            │
│                                                                     │
│ Level 3: 区域级故障（概率：低）                                      │
│   影响：整个区域（如华东）不可用                                     │
│   恢复：切换到异地灾备集群（< 5min RTO）                            │
│   降级：只读模式（可查看历史，无法新建任务）                         │
│                                                                     │
│ Level 4: 数据损坏/丢失（概率：极低）                                 │
│   影响：关键业务数据丢失                                             │
│   恢复：从备份恢复（RPO < 1h，RTO < 30min）                        │
│   降级：回滚到最近一致快照                                          │
└─────────────────────────────────────────────────────────────────────┘
```
