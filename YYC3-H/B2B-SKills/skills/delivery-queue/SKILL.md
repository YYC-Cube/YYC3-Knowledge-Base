# delivery-queue — 延时分段投递

按时间分段调度和投递消息，模拟人工发送节奏。

## 使用场景
- 将冗长的产品介绍拆分为 3-5 条易消化的消息
- 在最佳时间点（如客户当地上午9点）安排跟进
- 滴灌营销：按天间隔发送培育消息
- 通过控制外发节奏规避 WhatsApp 垃圾信息检测

## 命令
- `deliver:schedule` — 将消息加入待投递队列
- `deliver:list` — 查看待投递列表
- `deliver:cancel` — 取消已排期的投递
- `deliver:flush` — 立即发送所有待投递消息

## 配置
```yaml
default_delay_ms: 3000        # 段间延迟
max_segments: 10              # 每次投递最大段数
timezone: "{{timezone}}"      # 所有者时区
quiet_hours:                  # 静默时段（不发送消息）
  start: "22:00"
  end: "07:00"
```

## 使用示例
```
向 +1234567890 安排3段式产品介绍：
1. 公司概览（立即发送）
2. 产品亮点（5分钟后发送）
3. 价格咨询（15分钟后发送）
```

## 工作原理
1. AI 撰写完整消息序列
2. 技能按时间拆分为若干段
3. 每段附带投递时间戳入队
4. 后台工作线程按计划时间发送
5. 投递失败最多重试3次
