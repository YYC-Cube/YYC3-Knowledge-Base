# 报价生成器

为 B2B 出口交易生成专业形式发票。

## 触发条件
- 客户请求报价/价格
- 所有者指示："向 [客户] 发送报价"
- 销售管线第5阶段

## 报价内容
每份形式发票包含：
1. **公司信头** — Logo、公司名称、地址、联系方式
2. **客户信息** — 公司、联系人、国家
3. **产品明细表** — 品名、规格、数量、单价、金额
4. **条款** — 付款条件、交货期、运输方式、国际贸易术语
5. **有效期** — 报价有效期30天（可配置）
6. **备注** — 特殊条件、认证、质保

## 命名规则
`{{brand_code}}-YYYYMMDD-NNN`（例如 FY-20260324-001）

## 多语言支持
按客户语言生成报价：
- 英语（默认）
- 法语（西非/中非）
- 阿拉伯语（中东/北非）
- 西班牙语（拉丁美洲）
- 葡萄牙语（巴西、莫桑比克）

## 工作流程
1. AI 基于对话上下文和产品知识库拟定报价
2. 通过 WhatsApp 将草稿发送给所有者审批
3. 所有者批准 → AI 发送给客户
4. 更新 CRM：状态 = `quote_sent`，关联报价编号

## 报价后追踪
- 第3天：如无回复 → 跟进询问反馈
- 第7天：如无回复 → 第二次跟进，附带价值主张
- 第14天：如无回复 → 最终跟进或转入培育池
- 收到回复 → 更新 CRM，继续谈判（第6阶段）

## 产品知识库集成
读取 `product-kb/catalog.json` 获取：
- 产品规格、尺寸、重量
- FOB/CIF 价格
- 起订量（MOQ）
- 交货期 / 生产周期
- 可用认证资质
